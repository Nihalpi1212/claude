Nib portable mode

While this file sits next to nib.exe, Nib keeps its preferences, swatch and
graphic style libraries, added fonts, crash-recovery files and logs in the NibData folder
beside it, and writes nothing to %APPDATA%. Copy the whole folder to move Nib with its
settings. The first time NibData is created, any settings already in
%APPDATA%\Nib are copied into it; the originals are left where they were.

Keep this folder somewhere only you can write to: whoever can write here decides your settings,
including the plug-ins and fonts folders Nib loads from, and the Data Recovery copies of
your unsaved documents are kept here too.

Delete this file to use the normal per-user settings folder (%APPDATA%\Nib) instead.
If NibData can't be written (for example on a read-only drive), Nib logs a
warning and uses %APPDATA%\Nib instead.
