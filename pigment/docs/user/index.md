Pigment is a free, open-source image editor with layers, masks, adjustment layers, layer styles, type, vector shapes and brushes. Its menus, panels, tools and shortcuts follow Photoshop's layout, so Photoshop users find things where they expect them.

Pigment 0.5 is built on [PhotoCraft](https://github.com/storytold/photocraft), an open-source Photoshop-style editor by the ArtCraft team, and keeps almost all of it. It is a native app for Windows, macOS and Linux that draws the canvas on your graphics card, works offline and opens and saves layered PSD files. Pigment adds generative AI that uses your own OpenAI or Google Gemini account, and it opens the documents of Pigment 0.1 to 0.4.

Pigment is an alpha: much of Photoshop is there, but it is not yet a Photoshop replacement for daily professional work. See [Can Pigment replace Photoshop?](faq/replace-photoshop.md).
