# pinned one behaves differently (directory bundles create tiles/ only when they hold a tile,
# craft-raw decodes and rejects other inputs, the SVG importer's embedded-image budgets). Pigment
# changes none of the code they exercise (since the import, 15b8ea5, photocraft-format only gained
# its brand module, photocraft-raw two warning strings and the SVG importer one error string), and
# Cargo.lock's dependencies are upstream's. They fail in CI (a normal user, craft-fonts present) and
# here as root alike, each also when run on its own.

# turns this list into the cargo-nextest filter, by package and exact name) and runs
