Pigment portable mode

While this file sits next to pigment.exe, Pigment keeps its preferences, brush presets,
crash-recovery autosaves and startup state in the PigmentData folder beside it, and writes
nothing to %APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move Pigment with its settings.

Delete this file to use the normal per-user folders instead: %APPDATA%\Pigment for settings
and %LOCALAPPDATA%\Pigment\Recovery for crash-recovery autosaves. If PigmentData can't be
written (for example on a read-only drive), Pigment says so and uses those folders instead.
