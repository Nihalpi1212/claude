# Folio PDF — user guide

A quick map from "what I want to do" to where it is. Shortcuts show the Windows/Linux form; on
macOS use ⌘ instead of Ctrl. Press **Ctrl+/** inside the app for the full shortcut list.

## Opening and saving

| Task | How |
|---|---|
| Open a PDF | **File › Open** (Ctrl+O), drag files onto the window, double-click a PDF in your file manager, or pick one from the welcome screen's recent list |
| Several documents | Each opens in a tab. Ctrl+Tab / Ctrl+Shift+Tab switch tabs, Ctrl+W closes one |
| Password-protected files | You are asked for the password; wrong passwords can be retried |
| Save | Ctrl+S saves annotations and form entries into the same file. **Save As** (Ctrl+Shift+S) and **Save a Copy** are in the File menu |
| Reopen where you left | Documents reopen at the last page; the previous session's tabs are restored (Preferences › General) |
| File changed by another app | Folio reloads it automatically unless you have unsaved edits |

## Reading

| Task | How |
|---|---|
| Zoom | Ctrl + / Ctrl −, Ctrl+wheel, pinch, the zoom box (type a percentage), Fit page (Ctrl+0), Fit width (Ctrl+2), Actual size (Ctrl+1) |
| Pages | Page box in the toolbar, Page Up/Down, Home/End, Ctrl+Shift+N to go to a page, Alt+← / Alt+→ to go back and forward |
| Layout | **View › Page Layout**: continuous, single page, horizontal, wrapped; two-page spreads |
| Rotate the view | Ctrl+R / Ctrl+Shift+R (this does not change the file; use Organize pages for that) |
| Night mode, theme | **View › Night Mode** inverts page colours; **View › Theme** switches the app's light/dark look |
| Presentation | Ctrl+L (Esc to leave); F11 for full screen |
| Hand tool | H drags the page; V returns to text selection |
| Find | Ctrl+F. Enter / Shift+Enter move between matches; options for match case and whole words; the list button shows every match |
| Bookmarks, thumbnails, attachments, layers | Sidebar (Ctrl+Shift+B). Right-click a thumbnail to rotate, delete, insert or extract pages |
| Read out loud | **View › Read Out Loud** (Ctrl+Shift+Y) reads from the current page; right-click a selection to read only that; Esc stops |
| Copy a region as an image | **Edit › Take a Snapshot**, then drag over the page |
| Measure | Tools › Measure Distance: click two points. The unit is set in Preferences |
| Document properties | Ctrl+D: title/author/subject/keywords (editable), page size, PDF version, permissions |

## Commenting

Pick a tool from the toolbar (or the **Tools** menu); the bar below the toolbar shows its options
(colour, thickness, opacity, text size). Press **Esc** or **Done** to return to the selection tool.

| Tool | How it works |
|---|---|
| Highlight (U) | Select text to highlight it; **Free highlight** lets you paint over anything. Existing highlights can be moved and recoloured by double-clicking in highlight mode |
| Underline / Strikethrough / Squiggly | Choose the tool, then select text (or right-click a selection) |
| Sticky note (N) | Click where the note should go and type its text. Double-click a note later to edit it; hover it to read it |
| Text box (T) | Click on the page and type; drag to move, drag the corners to resize |
| Draw (D) | Draw freehand; strokes made in one go become one drawing. Undo with Ctrl+Z |
| Shapes | Rectangle, ellipse, line, arrow: drag on the page. Hold Shift while releasing to draw several |
| Stamps | APPROVED, DRAFT, … or your own text (edit the presets in Preferences); **Add image** places a picture |
| Eraser | Click any annotation to delete it. Delete/Backspace removes a selected text box, drawing, highlight or image |
| Comments panel | Sidebar › Comments lists every comment: click to jump, reply, edit the text, or delete. Filter and sort at the top |
| Undo / redo | Ctrl+Z / Ctrl+Shift+Z work for drawings and text boxes as well as for notes, shapes and page operations |

## Forms and signatures

| Task | How |
|---|---|
| Fill a form | Click into the fields; Tab or **Tools › Fill & Sign › Next Field** moves on. Calculated fields update like in Acrobat. Save with Ctrl+S |
| Highlight fields | Tools › Fill & Sign › Highlight Form Fields |
| Reset, export | Tools › Fill & Sign › Reset Form…, Export Form Data… (JSON) |
| Sign | Toolbar **Sign** › Add signature… Draw it, type it or upload an image (white backgrounds become transparent). Place it, drag it into position, resize with the corners, press Done, then save. Tick "Save for later" to reuse it from the Sign menu |
| Initials | Same as signatures, under Add initials… |

## Pages and documents

| Task | How |
|---|---|
| Organize pages | Ctrl+Shift+O: select pages (click, Shift-click, Ctrl-click), rotate, delete, drag to reorder, then **Apply** |
| Rotate / delete a page | Right-click its thumbnail in the sidebar, or use the organizer |
| Insert pages from another PDF | Tools › Insert Pages from File… (or from a thumbnail's menu) |
| Extract pages to a new file | Tools › Extract Pages… |
| Split a document | Tools › Split Document…: every N pages, or custom ranges |
| Combine files | File › Combine Files into PDF… (drag to order) |
| Create a PDF from images | File › New PDF from Images… (PNG and JPEG) |
| Crop | Tools › Crop Pages…: margins for the current page or all pages (reversible: enter 0 to restore) |
| Export | File › Export: Text, Page Images (PNG/JPEG at 96–300 dpi), Form Data, Flattened PDF |
| Flatten | File › Export › Flattened PDF bakes form values and comments into the pages so they can no longer be edited |
| Print | Ctrl+P: all pages, the current page or a range; choose whether comments and form fields print |

## Preferences (Ctrl+,)

Your name (used as the author of comments), appearance, session restore, default zoom and layout,
form field highlighting, measurement unit, drawing defaults and stamp presets.
